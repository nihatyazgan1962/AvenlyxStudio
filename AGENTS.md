# AVENLYX Studio — Agent Guidelines

Follow this directory layout strictly for all tasks:
- `desktop/`: Desktop codebase (C++20, Qt 6 Widgets, CMake).
- `mobile/`: Mobile codebase (Android / Flutter / etc.).
- `web/`: Web codebase.
- `dist/desktop/`: Final standalone desktop release bundle.
- `dist/mobile/`: Final mobile release packages (APK/AAB).
- `README.md`: Central documentation file at root.
